# Studio Reservation Software

Client-side multi-tenant reservation software for the fictional Echo Music Studio, database framework using Supabase with html frontend built with Flask. Account management system allows users to register and login using their email and a password, handled by Supabase, and can make reservations under their account. **DO NOT ENTER ANY SENSITIVE INFORMATION. I AM NOT CONFIDENT IN MY SECURITY INFRASTRUCTURE.**

## Requirements
Some python packages are required for client-side operation, mainly to assist with database queries.
- **Supabase**: Database management. Installation instructions can be found [here](https://supabase.com/docs/reference/python/introduction).
- **Flask**: Frontend building. Instructions found [here](https://flask.palletsprojects.com/en/stable/installation/).
- **Dotenv**: Environment access. [Pypi page](https://pypi.org/project/python-dotenv/).
